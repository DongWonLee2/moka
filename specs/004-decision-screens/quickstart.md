# Quickstart: 판단 결과 화면 연결 확인 (spec 004)

결과는 PASS / FAIL / SKIP / NOT_RUN으로만 적는다. 실행하지 않은 것은 PASS로 적지 않는다. 가짜 할 일과 가짜 키만 쓴다(사람 확인 6은 사람 자기 키).

## 1. 핵심 로직 (자동, 리눅스 CI `core-test`)

```
swift test
```

기대: 아래 시험이 모두 PASS이고, 기존 spec 001·002·003 시험과 시뮬레이터 golden이 그대로 PASS다.

- 이유 줄: 남은 날 네 경우(없음, 오늘, 남음, 지남), 하루 경계를 넘는 오늘, 손해 반올림 경계(0.24, 0.25, 0.74, 0.75), 판단 결과 없음·키 없음·질문 버전 다름이면 손해 없음, 미룬 횟수 0 (R-302~R-304, SC-301, SC-302, data-model §2)
- 게이트 판정: 열림 조건(시작 전, 물을 수 있음, concrete 미만), 열리지 않음(점수 없음, 임계값 이상, 도는 중, 통과함), 기다림 중 해시 같은 새 결과로 통과·다시 묻기·세 번 뒤 통과, 실패 해시로 통과, 물을 수 없게 되면 통과 (R-306, R-308, R-309, SC-304, SC-305, data-model §3)

## 2. 튜닝 계약 (자동, CI `tuning-test`)

```
cd tuning && python3 -m pytest
```

기대: 기존 시험 그대로 PASS. 이 spec은 스키마와 `questions.json`을 바꾸지 않는다.

## 3. 앱 빌드 (자동, CI `app-build`)

```
xcodegen generate && xcodebuild build -scheme Moka -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO
```

## 4. 앱 시험 (로컬 macOS, `MokaAppTests`)

```
xcodegen generate && xcodebuild test -scheme Moka -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO -only-testing:MokaAppTests
```

기대(가짜 공급자를 붙잡고 풀어 확인, 실제 시간을 기다리지 않음):

- 게이트: 열림, 제출 뒤 첫 행동 저장과 질의 1건, 통과 뒤 닫힘과 첫 행동 표시, 다시 묻기(칸에 지난 줄), 세 번 뒤 통과, 실패 일곱 종류와 401·키 지움에서 통과, 넘기기, 시작 버튼으로 닫힘, 노치 할 일이 바뀌면 닫힘, 같은 줄 제출은 질의 없음, 행동 로그 줄 수 그대로 (US2, SC-303~SC-306)
- 이유 줄: 판단 결과가 저장되면 노치 할 일은 그대로이고 이유 줄의 손해가 바뀜 (US1-5)
- 온보딩 키 단계: 저장, 빈 칸이면 다음 꺼짐, 건너뛰기, 저장 실패 문구, 이미 있음, 키 값이 설정·판단 결과·로그에 없음, 키 없이 끝낸 뒤 노치에 할 일이 뜸 (US3, SC-307, SC-308)
- 키 확인 표시: 401 뒤 노치 표시 값과 할 일 탭 표시 값이 켜지고, 키 저장·지움에 꺼지며, 키 없음에는 꺼져 있음. 노치 동작이 설정 창 기본 탭 요청을 남김 (US4, SC-309)

## 5. 화면 스냅샷 (로컬, CI `app-snapshots` 경고만)

새 상태: 시작 전·도는 중 펼친 화면의 이유 줄(손해 있음, 없음), 게이트 셋(묻는 중, 확인하는 중, 저장 실패), 온보딩 키 단계 셋(키 없음, 저장 실패, 이미 있음), 노치 키 확인 한 줄 셋(빈 상태, 시작 전, 도는 중), 할 일 탭 키 확인 한 줄. 라이트·다크. 기존 참조 이미지는 바뀌지 않아야 한다(SC-310). 시안 `~/Dev/ai-platform/projects/moka/design/004-mockup.html`과 나란히 보는 비교 페이지를 `design/pr-<번호>/index.html`에 만든다(ADR-0009).

## 6. 사람 확인 (확인용 빌드, 개인 팀 서명)

확인 순서를 적기 전에 그 상태를 지금 빌드에서 만들 수 있는지 먼저 본다.

|---|---|---|---|
| 6-1 | 자기 키가 저장된 상태에서 마감이 다른 가짜 할 일을 저장하고, 판단 결과가 붙은 뒤 노치를 펼치면 제목 아래 이유 줄(D-n, 손해, 미룬 횟수)이 보인다. 미루기 뒤 다시 뜨면 미룬 횟수가 1 올라 있다 | 설정 창 할 일 탭에서 할 일 저장 | US1, SC-301 |
